# AGENTS.md — правила для ИИ-агентов

Образовательная игра для уроков программирования с детьми. Перед работой прочитай `README.md` и `PROMPT.md`.
Пять игр сделаны по одним правилам: QuizShooter, QuizTowerDefense, QuizSnake, QuizPlatformer, QuizBreakout (`D:\02GameBrowser`).
Раздел «Вопросы» в `script.js` у всех пяти одинаковый — меняешь его в одной игре, повтори в остальных.

## Главное правило: PROMPT.md всегда соответствует игре

- Любое изменение поведения, чисел, графики, интерфейса или звуков — в том же изменении отрази в `PROMPT.md` (исправленный баг — с пометкой ⚠️).
- В конце `PROMPT.md` — полные исходники между `SOURCES:START` и `SOURCES:END`. Руками не править: после любого изменения `index.html`, `style.css` или `script.js` запусти `python tools/build.py` (он же пересобирает `codepen/index.pen.html`).
- `PROMPT_QWEN.md` — инструкция для урока. Весь промт — ОДИН блок ````text в начале файла (создание игры + 10 изменений через `LAB`), для детей он выглядит как просьба создать игру, файлы поданы как «шаблон проекта». Поменял поле `LAB` — обнови список в промте и таблицу «10 изменений».
- Перед коммитом: номер `?v=` в `index.html` увеличен (у CSS и JS одинаковый), `python tools/build.py` запущен.

## Ограничения кода

- Только HTML, CSS и чистый JavaScript (Canvas 2D) в трёх файлах, графика — эмодзи. Без библиотек, TypeScript, React, сборки.
- Простой код для детей: объекты и функции, без классов, подробные комментарии на русском. Значения `LAB` по умолчанию = обычная игра.

## Проверка

`python -m http.server 8000` в папке игры → http://localhost:8000. Проверь меню, настройки (мир, предмет, способ ответа), вопрос (кнопки и ввод), улучшения, конец игры. В консоли не должно быть ошибок.
